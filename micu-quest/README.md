# MICU QUEST · v3.6.0

병원 부서 전시회용 픽셀 RPG / 비주얼 노벨 약물 계산 시뮬레이션입니다.

- 공개 게임: https://shwldls.github.io/caltest/micu-quest/
- 기존 약물계산기: https://shwldls.github.io/caltest/ (별도 Flutter 앱, 수정하지 않음)
- 설치·계정·개인정보 입력이 필요 없는 정적 HTML/CSS/JavaScript 게임

## 플레이

근무 시작 → 병실 카드·배경 침상 직접 선택/랜덤 배정 → 의사 설명 → 주입 속도 계산 → 정답 반응 → 후속 처방 → 병실 완료 → 다음 환자 → 전체 완료.

`▼ 다음`을 누르면 타이핑 중인 대사를 완성하고, 다시 누르면 다음 대사로 진행합니다. PC에서는 Enter 또는 Space도 사용할 수 있습니다. 계산 중에는 숫자 입력, 화면 키패드, Enter 제출을 지원합니다. iPhone처럼 터치 입력을 사용하는 기기에서는 화면 키패드를 사용해 시스템 키보드가 게임을 가리지 않게 합니다.

오답은 다시 계산할 수 있고, 힌트는 농도 → 시간/체중 → 계산식 순서로 제공됩니다. 완료 기록은 현재 게임 세션에만 유지하며, 전체 완료 후 `다음 참가자 시작`으로 초기화합니다.

## 유지한 시나리오

| 병실 | 처방 | 교육용 예시 희석액(최종 부피) | 기본 정답(mL/hr) |
|---|---|---|---:|
| 01 패혈성 쇼크 | Norepinephrine 10 mcg/min | 6 mg / 200 mL | 20 |
| 01 추가 처방 | Vasopressin 0.03 units/min | 40 units / 100 mL | 4.5 |
| 02 CABG POD 2 / AF RVR | Herben 10 mg/hr | 100 mg / 100 mL | 10 |
| 02 약물 변경 / 처음 6시간 | Amiodarone 1 mg/min | 900 mg / 500 mL | 33.3 |
| 02 이후 18시간 | Amiodarone 0.5 mg/min | 900 mg / 500 mL | 16.7 |
| 03 기관삽관 / 70 kg | Precedex 0.4 mcg/kg/hr | 400 mcg / 100 mL | 7 |
| 03 진통제 / 70 kg | Remifentanil 0.05 mcg/kg/min | 2 mg / 40 mL | 4.2 |

원본의 세 가지 임상 상황, 체중, 일곱 계산 처방을 유지했습니다. Amiodarone 대사에는 계산 대상이 초기 부하 투여 이후 구간임을 명확히 했습니다. 계산 학습용 가상 처방이며 치료 선택이나 투여 적절성을 평가하는 시뮬레이터가 아닙니다. 실제 환자에게 적용하지 마세요.

**병원 표준 농도는 미확정입니다.** 모든 희석 농도를 교육용 예시로 명시합니다. 상단 설정에서 여섯 약물의 약물량과 최종 부피를 변경할 수 있습니다. 단위는 고정해 mg/mcg/units 입력 혼동을 줄이며, 처방 단위로 변환한 농도에서 문제·정답·힌트를 함께 계산합니다. 입력 숫자는 각각 유효숫자 12자리 이하여야 합니다. 부피는 희석제 부피가 아닌 **약물을 포함한 최종 부피**입니다.

최종 주입 속도는 소수 둘째 자리에서 반올림하여 소수 첫째 자리까지 표시합니다. 중간 계산과 원래 처방 용량·희석 농도는 반올림하지 않습니다. 20.0과 20처럼 같은 수는 모두 허용하며, 33.33 대신 반올림한 33.3을 입력해야 합니다. 진행 중인 병실에서는 농도를 잠가 계산 도중 문제가 바뀌지 않게 합니다. 농도와 표시 속도는 `micu-quest:settings:v3.1` 이름으로 해당 브라우저에만 저장하며 기존 계산기의 저장 공간을 건드리지 않습니다.

공식 의약품 라벨 참고(시나리오 전체의 임상 적절성 또는 병원 표준 농도를 승인하는 근거가 아님):
- [DailyMed Amiodarone](https://dailymed.nlm.nih.gov/dailymed/lookup.cfm?setid=d8d04647-8e25-4127-8ecf-360ce1991c2f&version=6)
- [DailyMed Precedex](https://dailymed.nlm.nih.gov/dailymed/fda/fdaDrugXsl.cfm?setid=548a88c0-afda-427e-75ac-5af0cfa2224c)

## 구현과 배포

- `core.mjs`: 원본 시나리오, 단위 변환, 농도 설정 검증, 정답 판정, 상태 전이
- `app.mjs`: 타이핑, 대화/계산 UI, 키패드, 애니메이션, 설정, 선택 가능한 효과음
- `styles.css`: PC 16:9 / 모바일 전용 레이아웃, safe-area, dvh, reduced-motion
- `assets/ward-v3.jpg`, `assets/characters-v3.png`: 사용자 레퍼런스 병실과 투명 캐릭터 아틀라스. 기존 SVG 인물·이모지를 사용하지 않음
- PC는 16:9 화면, 모바일은 병실/대화와 처방/키패드 전용 배치. 작은 화면 및 가로 방향에서 세로 스크롤을 지원합니다.
- 외부 CDN·폰트·서비스 호출 없이 실행되며, 이미지 생성 기능은 런타임에 필요하지 않습니다.

기존 `.github/workflows/deploy.yml`은 Flutter 앱 검증·빌드 후 `micu-quest/`를 복사해 gh-pages에 함께 배포합니다. 이 게임 변경으로 `lib/`, `web/`, 기존 계산기 테스트, 배포 설정은 변경하지 않습니다.

검증: `node --test micu-quest/tests/core.test.mjs`.

실제 브라우저 QA와 검증 한계는 [QA.md](./QA.md), 그래픽 제작 내역은 [ASSETS.md](./ASSETS.md)를 참고하세요.

## v3.1 기본 설정

사용자가 제공한 설정 화면의 여섯 희석값을 기본값과 예시값 복원에 반영했습니다. 대사 속도는 보통(26 ms)입니다. 기존 접속 브라우저도 이번 기본값으로 시작하도록 게임 설정 저장 키를 갱신했습니다. 이후 변경한 설정은 계속 저장됩니다. 교육용 예시 표시는 유지합니다.

## v3.2 전시회 참가자 전환과 효과음

병실 선택 화면의 COMPLETE, 다시 도전 배지 및 누적 완료 수를 제거했습니다. 랜덤 배정은 매번 세 병실 전체를 대상으로 합니다. 병실 결과 화면의 다음 참가자 시작 버튼은 이전 참가자 기록을 초기화하고 병실 선택으로 이동합니다. 같은 참가자가 여러 병실을 이어서 푸는 기존 진행은 유지됩니다.

v3.2 사운드는 기본 꺼짐이며 버튼에 소리 켬/끔을 표시합니다. 켤 때 확인 멜로디가 재생되고 클릭·정답·오답에 각각 효과음이 납니다. AudioContext가 실행된 뒤 재생하며 시작 실패 시 안내합니다. 이 버전에는 배경 음악이 없었으며, v3.5에서 추가했습니다.

## v3.4 실제 상황에 가까운 의사 대사

세 병실의 모든 설명·정답 반응을 환자 상태 공유 → 처방 전달 → 펌프 속도 확인 흐름으로 다듬었습니다. 정답 후에는 처방 확인과 다음 처방으로 연결하고, 오답 시에는 처방 단위·희석 농도를 함께 재확인하는 말투를 사용합니다. 환자 정보, 일곱 처방의 용량·단위, 교육용 희석 설정, 소수 첫째 자리 정답 판정은 그대로 유지합니다.

## v3.5 배경음과 대사 타이핑 소리

상단 소리 켬을 누르면 작은 음량의 오리지널 8마디 배경음이 반복됩니다. 대사에는 짧은 합성 음성이 글자 표시와 함께 울립니다. 언더테일처럼 글자에 맞춰 말하는 효과이며, 원작 음원·멜로디·캐릭터 음성은 사용하지 않습니다. 소스는 `audio.mjs`이고 외부 음원 다운로드가 필요 없습니다.

게임 설정에서 배경음(작게 재생/끔), 대사 타이핑 소리(켬/끔)를 각각 저장할 수 있습니다. 상단 소리 끔은 배경음·대사음·효과음을 모두 멈춥니다. 대사 즉시 표시, 다음으로 대사 전체 표시에서는 글자 소리가 몰아서 재생되지 않습니다. 화면을 벗어나면 모든 소리를 정리하고 돌아온 뒤 다음 버튼 조작에서 다시 시작합니다. 최초 소리 시작은 사용자 조작이 필요합니다.

검증: `node --test micu-quest/tests/*.test.mjs`. 실제 기기 음량과 무음·오디오 출력 설정에 따른 청취는 사용자 기기에서 확인해야 합니다.

## v3.6 소리별 음량 조절

게임 설정에서 배경음, 대사 타이핑 소리, 버튼 효과음, 정답 효과음, 오답 효과음을 각각 0~100%로 조절합니다. 0%는 해당 소리만 끕니다. 듣기로 해당 소리를 미리 들어볼 수 있으며 전체 소리가 꺼져 있으면 설정 안의 전체 소리 켜기를 먼저 누릅니다.

슬라이더는 즉시 적용하고 설정 저장으로 해당 브라우저에 유지합니다. 취소·닫기·Escape는 저장 전 음량을 복원합니다. 기본값은 배경음 25%, 대사음 40%, 나머지 50%로 기존 체감 음량을 보존합니다. 배경음 100%는 이전보다 4배, 대사음은 2.5배, 효과음은 2배의 합성 신호 진폭입니다. 이전에 배경음·대사음을 끈 설정은 0%로 이전합니다. 기기의 미디어 음량과 별도로 적용됩니다.
